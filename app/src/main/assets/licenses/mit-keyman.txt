Keyman keyboard layouts
=======================

The on-screen key grids for 862 of this app's layouts were converted from
the touch layouts in the Keyman keyboards repository. Each keyboard there
carries its own MIT licence, differing only in the copyright holder; the
shared licence text appears once below, followed by the holder for every
keyboard used.

Only the key grid was taken. The layouts were converted by this project's
own code and are not the upstream files.
