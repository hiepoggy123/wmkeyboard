# Security Policy

## Supported Versions

Security updates are only provided for the latest release of WMKeyboard. We encourage all users to always update to the latest version to ensure they have the most recent security patches and features.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

We take the security of WMKeyboard seriously. If you discover a security vulnerability, please report it privately.

**Please do not open a public issue.** 

Instead, please use GitHub's private vulnerability reporting feature to report the issue:
1. Go to the **Security** tab of this repository.
2. Click on **Advisories** in the sidebar.
3. Click the **Report a vulnerability** button.
4. Provide as much detail as possible, including steps to reproduce the issue, the potential impact, and any possible mitigations.

Alternatively, you can report the vulnerability by emailing **arianmollik323@gmail.com**.

We will review the report, triage the issue, and respond to you as soon as possible. Thank you for helping to keep WMKeyboard secure!
