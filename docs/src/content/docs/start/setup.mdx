Installing WM Keyboard doesn't make it your keyboard. Android keeps every installed input method switched off until you enable it and then pick it as the active one. The app's Home screen has a card that walks you through both steps and tells you the moment you're done.

## Using the setup card

The card sits at the top of the app's Home screen, always. It isn't a first-run-only banner, so you can come back to it any time. While it's on screen it checks Android's input-method state about once a second. There's no callback for "the user switched keyboards" while your app sits behind a system dialog, so polling is the only way to notice. The card shows one of three states:

1. **Not enabled.** The card reads "Enable WM Keyboard in system settings, then select it as your input method." It offers two buttons. **Enable keyboard** opens Android's input-method settings list. **Switch keyboard** opens the system's keyboard picker directly.
2. **Enabled, not selected.** The card reads "WM Keyboard is enabled. Use the button below to switch to it." Only **Switch keyboard** shows now.
3. **Enabled and selected.** A checkmark icon appears, tinted with the app's accent color. It isn't necessarily green, because it follows your theme. The card reads "WM Keyboard is your active keyboard." Nothing left to do.

Tap **Enable keyboard** to open the system screen. Turn WM Keyboard's toggle on there. Tap **Switch keyboard** to open Android's "Change keyboard" sheet, which lists every enabled input method on the device. Tap WM Keyboard in that sheet to make it active. Both screens are also reachable through Android's own Settings app, if you'd rather not use the card at all.

## What the system permission warning means here

Enable any third-party keyboard and Android shows its own warning about keyboards being able to see everything you type. That text is the stock OS wording. WM Keyboard doesn't write it and can't customize it, and it reads a little differently on each Android version. The warning exists because *some* keyboards phone data home, which makes it worth knowing what this one does.

Core typing runs entirely on-device: the spelling dictionaries, transliteration, emoji search, prediction, everything you actually type with. All of it works with no network connection at all. A handful of optional toolbox features do reach the network, and only when you open them yourself. Weather, the word-definition lookup, translate, GIF and sticker search, and web and image search each call their own service, and several want your own API key before they work at all. None of that runs in the background, and none of it runs while you're just typing. See [Privacy at a glance](/privacy/overview/) for the full breakdown.

## Running the setup wizard

The first time you open the app, it drops you into a short setup wizard instead of the Home screen. Every choice writes straight to settings as you make it. Going back, skipping ahead, or tapping **Skip** in the top corner therefore loses nothing, and you can change any of it again later.

The wizard tailors itself to a short quiz on its second page, so not everyone sees every step. The full list:

<Steps>

1. **Welcome.** The setup card from above, embedded in the wizard's first page. Enable and select WM Keyboard here and the wizard advances on its own. You do not have to tap Next after you come back from system settings.

2. **Make it yours.** Three quick questions, all optional. How many languages you type in, whether you want a simple or a fully loaded keyboard, and how private it should be. Each answer's subtitle spells out what picking it changes. Answers apply their defaults on the spot, and the rest of the wizard trims itself to match. Leave all three alone and you get the short version. [What the quiz changes](#what-the-quiz-changes) below lists every setting each answer writes.

3. **Your languages** *(hidden if you answered "just one" language and only one is enabled)*. Your currently enabled languages come first, each with its layouts individually switchable, then a short **Suggested for you** list, then a search box for the other 350-odd. The suggestions come from your phone's own language settings and region. See [Suggested languages](/languages/overview/#suggested-languages) for exactly what's read. Adding a language during setup enables its first layout only. Add the other layouts later from Settings.

4. **Look & feel.** Theme mode (Auto/Light/Dark/AMOLED), a Material You colors toggle, a keyboard theme picker, an emoji-row mode choice, and a symbol row toggle.

5. **Emoji font** *(only if your phone's emoji font can't draw everything, or if the phone ships an emoji set of its own)*. Pick which emoji you want to see, with a live preview of each option. A toggle hides emoji your device would otherwise draw as blank boxes, and it appears only when there are any. A pointer to importing a full emoji font sits alongside it. Samsung phones get this step even though nothing is missing on them: everything draws, but it draws in Samsung's set rather than the images most other phones show.

6. **Typing feedback** *(skipped for "keep it simple" answers)*. Haptics, key sounds, and the key popup bubble.

7. **Spacebar & keys** *(skipped for "keep it simple" answers)*. One choice sets both spacebar-swipe directions, short and long, and a "Recommended" badge follows your quiz answer. There's also a toggle to replace the <KeyCap>🌐</KeyCap> key with an emoji key, and a number row toggle.

8. **Worth knowing about.** A short tour of the features most keyboards don't have: smart chips, tool hotwords, the toolbox, photo backgrounds, clipboard history and more. Most cards carry a switch right on them. The rest say where the feature lives.

9. **Your tools** *(only for "show me everything" answers)*. Every toolbar tool, each with its own switch, plus quick "Recommended" and "Everything" buttons.

10. **Tool setup** *(only for "show me everything" answers with Calendar, Weather, or Compass enabled)*. First-run choices for whichever of those you kept: alternate calendars, a saved place and temperature unit, or a qibla toggle.

11. **Try your keyboard.** A live text field, so the keyboard appears in the theme you just picked. Two or three "try this" prompts come with it, drawn from what you enabled. Type `12*8=` for a smart chip, type a tool's name for its hotword chip, or open the toolbox.

</Steps>

## What the quiz changes

Each answer does two things: it writes a few settings there and then, and it decides which of the later pages you get. Here's the whole mapping, so you can see what you agreed to.

**How many languages do you type in?**

| Answer | What it writes | What it does to the wizard |
|---|---|---|
| Just one | Both spacebar swipes (short and long) move the cursor, and the <KeyCap>🌐</KeyCap> key becomes an emoji key | Your languages is skipped, unless you already have two or more enabled |
| Two or more | Both spacebar swipes change the language, and the <KeyCap>🌐</KeyCap> key stays a language key | Your languages appears |

Neither is a one-way door: the Spacebar & keys page later offers the same choice again, with a **Recommended** badge on whichever one matches your answer.

**What kind of keyboard do you want?**

| Answer | Toolbar tools it turns on | What it does to the wizard |
|---|---|---|
| Keep it simple | Eight: emoji, GIFs, stickers, clipboard, voice typing, AI writing tools, grammar check, and the settings shortcut | The short path. No Typing feedback, no Spacebar & keys, no Your tools |
| A good middle | 21: those eight plus themes, dictionary, fancy text, translate, autocorrect, snippets, one-handed, split, text editing, handwriting, text scan, undo and redo | Adds Typing feedback and Spacebar & keys |
| Show me everything | 35: those 21 plus Wikipedia, power saving, keyboard modes, numpad, special symbols, calculator, unit converter, currency, password generator, calendar, weather, media controls, apps and hide keyboard | Adds Your tools, and Tool setup when calendar, weather or compass is among them |

A set that can't run in full on your phone gets topped up rather than left short. Part of it may be unavailable, because a Lite build has no handwriting and no text scan, or because the phone has no Google services. Wikipedia and power saving then come in behind whatever's missing, so a "recommended" set never quietly arrives two tools smaller.

**How private should it be?**

| Answer | What it writes |
|---|---|
| Standard | Nothing. The shipped defaults already are the standard behaviour |
| Extra strict | Turns off **Learn from typing**, **Clipboard history** and **Count typing statistics**, and adds the Incognito tool to whichever set the question above landed |

Leave the quiz alone entirely and you get the short page list, the same one "keep it simple" gets, plus the middle tool set when the wizard closes.

## Switching keyboards later

Once WM Keyboard is set up, there are a few ways to change which keyboard is active, or which of WM Keyboard's own languages is:

- **The Home screen's Switch keyboard button** is always there, not just during setup. Tap it any time to reopen the system picker.
- **Android's own switcher notification** shows up automatically, as a "select input method" notification, whenever two or more keyboards are enabled on the device. Tap it to open the same system picker.
- **The <KeyCap>🌐</KeyCap> key and spacebar swipes** cycle between WM Keyboard's *own* enabled languages. They don't open the system keyboard picker, so they can't switch you to a different keyboard app.

The option below lists WM Keyboard's languages individually in Android's own switcher sheet, rather than as one generic "WM Keyboard" entry. It's on by default. Turn it off to keep every switch inside the keyboard.

## Options

- **Show app name first** (off by default, and only shown while the option above is on). Prefixes each subtype's label with "WM Keyboard ·" instead of just the language name.

## Running it again

The wizard isn't a one-shot. <SettingsPath path="About / Run setup again" /> replays it whenever you like. A replay never rewrites your settings on its own, because the quiz remembers your old answers and only changes what you actually tap. The Welcome page stays out of the way when the keyboard is already enabled and selected. Finishing a replay drops you back on the About screen.

## Details & edge cases

- Whether the wizard appears has nothing to do with whether the keyboard is enabled. A "have you finished onboarding" flag drives it, not a check of Android's input-method state. Enable and select WM Keyboard entirely from system Settings, without ever opening the app, and the wizard still appears on first launch. Its Welcome page just already shows the "done" state and lets you move straight past it.
- Skipping the wizard early still lands a sane tool set. Finishing it, or skipping over the untouched everything-enabled default, replaces that default with the recommended set. Answer "keep it simple" first and you get the smaller essential set instead.
- On a Lite build, the Tools page doesn't offer handwriting, OCR, QR/barcode scanning, document scanning, or grammar checking as options at all, since those features aren't built into that edition. See [Full vs Lite](/start/editions/).
- Installing over an existing WM Keyboard install (same signing key) keeps the wizard from running again. `onboardingDone` is a regular setting, so it carries over like any other. A clean reinstall, or a new phone with no settings backup, shows the wizard again. See [Installation](/start/installation/) for what does and doesn't carry over.
