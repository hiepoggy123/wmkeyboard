## Choosing an emoji font

<SettingsPath path="Emoji / Emoji style / Emoji font" />

WM Keyboard ships no emoji font of its own — it draws emoji with whichever one you pick here, and a preview row on the settings screen renders 😀😂🥰😎🤔👍❤️🎉 through the real rendering pipeline so you see exactly what the keyboard will show, not a mockup.

- **System** (default) — your phone's own emoji pack. On Samsung phones that's Samsung's set, not Google's.
- **Google** — fetches Noto Color Emoji, the stock-Android look, once through the system font provider and caches it on the device.
- **Installed** — an emoji font from [Addons](/addons/installing/), such as Twemoji or OpenMoji, picked from a list of whatever you've installed. Deleting the font you currently have selected falls back to System automatically.
- **Custom** — a single font file you import yourself, kept separate from the addon library.

Text you send is always plain Unicode, regardless of which font you pick — the app or phone on the other end draws it with its own emoji font. This setting only changes how emoji look while you're composing them.

:::note
An emoji font converted from a color format usually has no variation-selector table, so ❤️ (U+2764 + the invisible U+FE0F that makes it draw as color) can't resolve in it. WM Keyboard strips that invisible selector before handing the glyph to your chosen font, rather than let it fall back to the system font and look inconsistent with the rest of the row.
:::

## Fixing emoji that won't display

Older phones and some OEM skins ship an emoji font that predates the newest emoji, and those show up as an empty "tofu" box. There's no one-tap repair for this — two settings work together instead:

<SettingsPath path="Emoji / Emoji style / Hide emoji this phone can't display" />

This toggle (off by default) checks both your chosen font and the phone's own system font, and only hides an emoji from the panel, search, and suggestions when **neither** can draw it. An emoji your chosen font is missing but the phone's system font can still draw isn't hidden — it's silently drawn in the system font instead, in a different style from the rest of the row, so it still gets through.

To actually fill the gaps rather than hide them, switch **Emoji font** above to Google (Noto Color Emoji has close to complete Unicode coverage) or install a complete addon font like Twemoji or OpenMoji from [Addons](/addons/installing/).

## Emoji search in your language

<SettingsPath path="Emoji / Emoji panel / Emoji keywords" />

Emoji search ships with English and Bengali keywords built in, so it works out of the box in both languages. For anything else, download a keyword pack — WM Keyboard's data repository carries packs for 125 languages, each a small gzipped file of `{emoji, name, keywords, category}` entries sourced from Unicode CLDR.

<PhoneFrame caption="The Emoji keywords screen, with per-language download and delete controls.">
  {/* shot: emoji/keyword-packs */}
</PhoneFrame>

Packs stack on top of the bundled English/Bengali keywords rather than replacing them, so downloading, say, Spanish adds Spanish search terms without losing the two you already had.

**Download automatically** (on by default) fetches a keyword pack the first time you enable a language you type in, and skips anything already downloaded. Turn it off and packs only arrive when you tap Download next to a language yourself.

Deleting a downloaded pack leaves a marker behind so automatic download won't silently re-fetch it — if you want it back, download it again explicitly.

You can also import a pack by hand: either a plain tab-separated file (`emoji`, comma-separated keywords, optional display name) or the data repository's own JSON file directly — WM Keyboard sniffs the format so you don't have to convert it first. Imported packs are kept separate from downloaded ones on disk, but merge into the same search index.

## Emoji suggestions while typing

<SettingsPath path="Emoji / Suggestions / Emoji suggestions" />

Turn this on (it's on by default) and matching emoji append to the end of the suggestion strip as you finish typing a whole word — "birthday" offers 🎂🎉🥳🎁, and it works the same way for Bengali words. It also fires on an empty buffer from words you've just typed, learned over time, so a word like "you" can suggest ❤️ without you typing anything new.

<PhoneFrame caption="Emoji suggestions appended to the strip after typing a whole word.">
  {/* shot: emoji/word-suggestions */}
</PhoneFrame>

**Emoji suggestion tap** decides what happens when you tap one:

- **Replace word** (default, Gboard-style) — swaps the word you typed for the emoji. Typing "birthday" and tapping 🎂 leaves just 🎂.
- **Keep word** — adds the emoji after the word instead: "birthday 🎂".

## Inline emoji search and shortcodes

Typing a `:` isn't part of the suggestions setting above — it's a separate toggle, and it lives on the Typing settings screen rather than the Emoji screen:

<SettingsPath path="Typing / Suggestions / Inline emoji search" />

With this on (the default), typing a colon at a word boundary turns the whole suggestion strip into an emoji search: `:cat` offers 🐱 and friends, replacing ordinary word suggestions entirely while the search is active. Backspacing over the colon returns to normal suggestions.

<PhoneFrame caption="Typing a colon turns the suggestion strip into emoji search results.">
  {/* shot: emoji/inline-colon-search */}
</PhoneFrame>

The same toggle also covers exact shortcode names. If you type the *closing* colon and the text between the two colons is an exact match — `:tada:`, `:thumbsup:` — the whole thing is replaced with the emoji immediately, with no tap needed. A name that's only a partial or unknown match is left as ordinary typed text; an unrecognized shortcode is never silently eaten.

## The dedicated emoji row

<SettingsPath path="Emoji / Emoji row / Emoji row" />

A row of your own emoji, similar to Gboard's, that sits between the toolbar and the keys.

- **Off** — no emoji row.
- **Button** (default) — adds a toggle to the toolbar strip that swaps it for the emoji row on tap.
- **Own row** — keeps the emoji row permanently visible above the keys.

<PhoneFrame caption="The emoji row in Own row mode, above the key rows.">
  {/* shot: emoji/emoji-row-own */}
</PhoneFrame>

Once the row is showing (anything other than Off), three more settings appear:

- **Emoji row content** — Most used (default), Recent, or Favourites. Whichever you pick, your favourited emoji always sort to the front.
- **Emojis in the row** — a slider from 3 to 16, defaulting to 8. The row splits its width into that many slots and shrinks the emoji to fit, so a higher number packs more emoji in at a smaller size.
- **Scroll the emoji row** — off by default, meaning the row shows exactly that many slots and nothing past the last one, so a sideways swipe on the row can't slide the whole thing out from under your finger. Turn it on to reach the rest by swiping.

Where the row sits relative to the toolbar and the symbol row — above them, below them, in between — is a separate setting under Rows & bars on the settings home screen, not on this screen.

## Details & edge cases

- **The font preview is exact, not illustrative.** The eight-emoji preview row on the Emoji font setting runs through the same shaping code the keyboard itself uses, including the ❤️ variation-selector workaround — what you see there is what you'll get on the keys.
- **Installed emoji fonts share storage with text fonts**, but are listed separately in the picker — a colour emoji font would make an odd choice for key labels, so the two lists never cross over.
- **Bundled Unicode data, not user data.** Keyword packs, shortcode names, and the trigger words behind emoji suggestions are all static files that ship with the app or download from WM Keyboard's own data repository — none of it depends on what you type.
- **Emoji predictions can drop under battery pressure.** Power Saving mode has its own setting that can suppress emoji predictions to save cycles; see [Power saving](/typing/power-saving/) for that behavior.
- **Kaomoji and ASCII emoticons are a separate system.** They live behind their own two panel tabs, don't use the emoji font setting at all (they're plain text), and aren't searchable or favoritable the way real emoji are — see [Kaomoji & text art](/emoji/kaomoji/).
- **Two other keys can open emoji access directly**: the language-switch key can be replaced with an emoji key (on by default, under Layout & size), and the comma key can be too (off by default). Both are separate from the emoji row and the toolbar button described above.
