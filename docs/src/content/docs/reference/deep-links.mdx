## Planned coverage

- Settings deep links: the exact allowlist — typing, appearance, themes, languages, tools, search
- Launcher shortcuts (long-press the app icon): Tools, Languages, Typing, Themes
- Addon links: wmkeyboard://addons, wmkeyboard://repo?url=…, wmkeyboard://addon?repo=…&id=…
- File associations: opening .wmtheme.json / .wmlayout.json / .wmstickers / .wmicons / .wmplugin / snippets / backups installs them
- Security: settings intents are explicit (not web-reachable); addon links never auto-install
