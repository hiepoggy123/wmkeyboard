The Privacy screen collects on-device learning, incognito, Android's own backup opt-in, and the one button that clears learned data: three groups, in that order, nothing else. This page is the field reference; for the reasoning and the rest of the privacy story, start at [Privacy at a glance](/privacy/overview/).

## Options

<SettingsPath path="Privacy" />

### On-device learning

<SettingsPath path="Privacy / On-device learning" />

| Setting | Control | Default |
|---|---|---|
| Learn from typing | Toggle | **On** |
| Add words to the system dictionary | Toggle | Off |
| Expand dictionary shortcuts | Toggle | Off |
| Incognito mode | Toggle | Off |
| Follow private browsing | Toggle | **On** |

**Learn from typing** is the master switch for the on-device word and word-pair lexicon; turning it off stops new learning without deleting anything already learned. **Add words to the system dictionary** additionally writes learned words to Android's own personal dictionary (System Settings → Languages & input → Dictionary) so other keyboards and the platform spell checker see them too. It's the one setting in this group that writes outside the app, which is why it defaults off even though the keyboard's own learning already covers the same ground. **Expand dictionary shortcuts** reads that same system dictionary the other way: type a shortcut you've defined there (say "omw") and it offers the full phrase ("on my way") as a suggestion.

**Incognito mode** and **Follow private browsing** are covered in full, including exactly what pausing learning and clipboard capture means, on [Incognito & secure fields](/privacy/incognito/). Worth knowing here is that **Follow private browsing** defaults to **on**, the opposite of what its neighbor "Incognito mode" does, and that two related toggles, **Pause learning** and **Pause clipboard capture** (both on by default), live on a separate screen, <SettingsPath path="Tools / Incognito" />, not on this one. "Follow private browsing" itself also appears on that Tools screen; it's the same setting shown in both places, not a second copy.

### Android backup

<SettingsPath path="Privacy / Android backup" />

| Setting | Control | Default |
|---|---|---|
| Back up with Android | Toggle | Off |

**Back up with Android** folds the keyboard into Android's own backup and phone-to-phone transfer system. Off by default, so nothing this keyboard stores is copied anywhere until you turn it on. Once on, settings, themes, layouts, snippets, learned words, sticker and icon packs, and plugins are all included, and so are any saved API keys (Translate, AI tools, and the rest). Left out, because the keyboard can fetch them again on its own: voice and AI models, downloaded dictionaries, and emoji-keyword packs. A cloud backup is only made on devices that can encrypt it with your screen lock.

<PhoneFrame caption="The info dialog for Back up with Android, listing what's included and excluded.">
  {/* shot: reference/settings/privacy-backup-info-dialog */}
</PhoneFrame>

This is a different screen from the sibling **Backup & restore** item on the Settings home screen (route `backup`), which exports and imports a settings file by hand and never touches Google at all. See [Backup & restore](/privacy/backup/) for both paths side by side, and the [Backup & restore reference](/reference/settings/backup/) for that screen's own fields.

### Your data

<SettingsPath path="Privacy / Your data" />

A single button, **Clear learned words**: no toggle, no confirmation prompt. Tapping it immediately deletes three files: your word and word-pair lexicon, your emoji-usage history, and your Chinese/Japanese/Cantonese pick history. It does **not** touch the language-mix tracker that remembers which language you tend to reach for when mixing languages.

<PhoneFrame caption="Clear learned words, the only control in the Your data group.">
  {/* shot: reference/settings/privacy-clear-learned-words */}
</PhoneFrame>

This is the only bulk clear on this screen. Personal dictionary entries, clipboard history, and downloads each have their own per-item controls elsewhere. See [Your data on device](/privacy/data/#clearing-whats-stored) for the complete map of where every other category's clear control actually lives.

## Details & edge cases

- **"Clear learned words" is one bulk action, not a per-category picker.** There's no dialog letting you choose which of the three files to wipe: tapping the button deletes all three at once, instantly, with no undo.
- **"Follow private browsing" isn't two settings.** The row here and the row of the same name under <SettingsPath path="Tools / Incognito" /> both read and write `autoIncognito`; flip it in either place and the other reflects the change.
- **Saved API keys are included in an Android backup**, not excluded the way large downloads are. If that matters to you, use [Backup & restore](/privacy/backup/)'s manual export instead, which never leaves the device.
- **A cloud backup needs an encryptable screen lock.** On a device without one, turning "Back up with Android" on has nothing to actually back up into: Android's own backup system requires it.
- **The footer caption names the whole network side.** The screen's own note reads: "Typing runs entirely on this device. Dictionaries, prediction, autocorrect, transliteration and emoji search are bundled with the app, and none of them need a network connection. There is no telemetry and no analytics. Network access is per tool and only on the tap that uses it — translate, weather, web and image search, GIFs and stickers, dictionary lookup and the AI tools — and every one of them can be switched off under Tools." It used to name only the weather tool, which undersold it. See [Privacy at a glance](/privacy/overview/) for the same list with per-tool detail.
- **No edition differences.** Every setting on this screen behaves the same on both the full and lite builds.
