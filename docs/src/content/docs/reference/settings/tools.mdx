The Tools screen is the enable switch and settings entry point for every one of WM Keyboard's 60 tools, letting you turn a tool on or off, tint its icon, and tap through to its own options. This page is the field reference for that one screen; for how the toolbar and toolbox actually work (pinning, dragging, groups, direct boot), see [The toolbar](/tools/overview/) instead.

## The tool list

<SettingsPath path="Tools" />

Reach it from Home → **Tools**, or by searching "Tools" in settings search. A deep link also works: `wmkeyboard://settings/tools`.

A **Colorful tool icons** toggle sits above the list, on by default. It tints each tool's icon with its own accent color, here and in the toolbox alike; turn it off and every icon falls back to the theme's plain foreground color. While it's on and you've recolored at least one tool, a **Reset custom colours** button appears above the list and clears every per-tool override in one tap.

Below that, every tool gets one row: icon, name, a one-line description, an optional tune icon, and a switch. Tapping the switch enables or disables the tool; tapping anywhere else on the row opens that tool's own settings screen.

:::note[This screen doesn't control toolbar or toolbox placement]
Disabling a tool here removes it from the toolbar, the toolbox, and its hardware leader-key letter all at once, and that part is this screen's job. But *which* enabled tools are pinned to the toolbar bar itself, versus waiting in the toolbox, is a separate mechanism entirely: you drag tools between the two on the keyboard's own toolbox UI, and the toolbar's display options (height, spread vs. scroll, labels, grid size, and "Reset pinned tools") live under <SettingsPath path="Appearance / Toolbar" />. See [The toolbar](/tools/overview/) for all of that.
:::

### Groups

Tools are grouped by what they do, in this order:

| Group | Tools |
|---|---|
| Panels | Emoji, Clipboard, Snippets, Text editing, Numpad, Handwriting, Voice typing, Camera, Dictionary, Grammar check |
| Scanners | Text scan (OCR), QR & barcode scanner, Document scanner |
| Online tools | Translate, GIFs, Stickers, Web search, Image search, Wikipedia, Currency converter, AI writing tools |
| Create & convert | Special symbols, Calculator, Unit converter, QR code generator, Password generator, Typing speed test |
| Keyboard modes | Keyboard modes, One-handed mode, Split keyboard, Floating keyboard |
| Cursor | The twelve one-tap cursor moves, plus Hide keyboard |
| Quick actions | Undo, Redo, Autocorrect, Incognito, Sound & haptics, Themes, Power saving, Settings shortcut |
| Utilities | Flashlight, Compass, Bubble level, Calendar, Weather, Moon phase |
| Other | Media controls, Plugins |

A tool a future group forgets to claim still shows. It falls into the trailing **Other** catch-all, which is why Media controls and Plugins land there rather than in a more specific group of their own, and nothing ever goes missing from the list.

A tune icon marks the tools with settings beyond the switch. Exactly six are toggle-only here, because their real options live on other screens: **Unit converter**, **Settings** (shortcut), **Themes**, **Sound & haptics**, **One-handed mode**, and **Media controls**.

<Flavor edition="lite" /> hides the **Scanners** group entirely: Text scan, QR scan, and Document scanner are all unavailable, so the group has nothing left to show and doesn't render. **Panels** shrinks by two rows (Handwriting and Grammar check drop out) but keeps its name and the rest of its tools. See [Lite edition](#lite-edition) below for the complete gating rule.

## Opening a tool's own screen

Every tool's detail screen, reached by tapping its row above, starts with the same three things, then adds whatever that specific tool needs:

1. **Enabled**: the identical switch from the list screen, just repeated here.
2. **Icon colour**: only shown while **Colorful tool icons** is on. Tap it to open a color picker for just this tool's icon; the swatch reads "Default" until you customize it, then "Custom."
3. **Keyword shortcut**: a "Trigger words" field, shown only for the tools that ship a built-in keyword. Typing one of a tool's words on its own (`wiki`, `calc`, `qr`, and so on) offers a chip that opens the tool. This is the same feature documented in full on [Smart chips](/smart/chips/#keyword-chips-open-a-tool); this screen just lets you edit or clear the words for one tool at a time.

## Managers built into a tool's screen

A handful of tools carry something bigger than a row of toggles: a model downloader, a list editor, a location picker. All of them live inline, inside that tool's own detail screen; none of them is a separate destination in Settings' navigation, with the two exceptions called out at the bottom of this table.

| Tool | What's there | Notes |
|---|---|---|
| Voice typing | Recognition engine choice, plus the Whisper model manager | Only appears <Flavor edition="full" />. Default engine is **System recognizer**; switching to **Offline Whisper** reveals a **Translate to English** toggle (off by default) and the model list. Full details: [Voice typing](/tools/voice/), [Offline voice (Whisper)](/tools/whisper/). |
| AI writing tools | Provider chips (Claude, OpenAI, Gemini, Ollama, LM Studio, On-device) with per-provider API key or server fields, plus a local-model manager when On-device is selected | On-device is the only provider hidden on <Flavor edition="lite" />. See [AI tools](/tools/ai/). |
| Handwriting | A recognition-model manager, one entry per typed language | Each model is an on-demand ML Kit download of about 20&nbsp;MB. See [Handwriting](/tools/handwriting/). |
| Snippets | Full add/edit/delete list, plus import and export | Stored as a JSON file the tool manages itself. See [Snippets & text expansion](/tools/snippets/). |
| Weather | A location picker, plus a Fahrenheit toggle (off by default) | See [Instruments](/tools/instruments/). |
| Typing speed test | A Records group: tests completed, recent average, best score per test length, and a "Clear records" row (shown only once there's something to clear) | See [Utility tools](/tools/utilities/). |
| Plugins | A "Manage plugins" row | **This one opens a separate screen.** <SettingsPath path="Tools / Plugins" /> is just an entry point into [Plugins overview](/plugins/overview/), not an inline manager. |
| Stickers | A "Sticker packs" row alongside the tool's own settings | **Also a separate screen.** See [Stickers](/emoji/stickers/). |

## Lite edition

<Flavor edition="lite" /> hides five tools completely. There's no settings row anywhere, not even a switch you can't turn on:

- Handwriting
- Text scan (OCR)
- QR & barcode scanner
- Document scanner
- Grammar check

Two more flags narrow what's *inside* a tool without removing the tool itself: the **On-device** AI provider chip and the entire **Offline Whisper** engine option are both full-only, so AI writing tools and Voice typing still exist and still have a settings row on lite, just with fewer choices on it. Lite ships 55 of the 60 tools.

## Details & edge cases

- **All 60 tools start enabled.** A fresh install (or a reset) has every tool switched on; nothing is off by default, so a tool you don't see on the toolbar is waiting in the toolbox, not disabled.
- **Disabling a tool is one switch, not three.** It disappears from the toolbar, the toolbox, and its hardware leader-key letter simultaneously, and there's no way to keep one of those and drop the others.
- **The tune icon is a hint, not a guarantee of depth.** A handful of tools with a tune icon still only add one or two settings past the shared Enabled/Icon colour/Keyword shortcut rows; the icon just means "there's at least one more setting," not "there's a lot here."
- **A tool's icon color override survives disabling and re-enabling it.** Turning a tool off and back on doesn't reset any customization made on its detail screen.
- **Build-gated tools leave no trace.** A tool hidden by the lite edition doesn't appear as a disabled row anywhere: not in this list, not in settings search, not in the toolbox. The five lite-hidden tools are simply absent.
