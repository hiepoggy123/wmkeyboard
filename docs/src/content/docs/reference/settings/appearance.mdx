The Appearance screen is where the keyboard's look and feel come together: it's a hub for the theme, font, and icon pickers, plus the sliders that shape the keys themselves and the toolbar above them.

## Style

<SettingsPath path="Appearance / Style" />

Three rows that each open their own screen rather than settings inline:

- **Keyboard themes** — light, dark, AMOLED, and custom colors, background images, and theme import/export. Shows the active theme's name, or "Default" when you haven't picked one. Full details on [Themes](/themes/overview/).
- **Keyboard font** — Google Fonts, or a font file you import yourself. Shows "System default" until you pick something else. Full details on [Fonts](/themes/fonts/).
- **Icons** — swap any tool or key icon individually, or install a whole icon pack. Shows "Default" with nothing changed, the active pack's name once one is installed, or a count of individually-changed icons. Full details on [Icon packs](/themes/icon-packs/).

Reference pages for each of these three screens: [Keyboard themes](/reference/settings/themes/), [Keyboard font](/reference/settings/fonts/), [Icons](/reference/settings/icons/).

## Keys

<SettingsPath path="Appearance / Keys" />

Three sliders that apply to every key, keyboard-wide, regardless of which theme or layout is active:

| Setting | Range | Default |
|---|---|---|
| Key corner radius | 0–28 dp | 8 dp |
| Key label font size | ×0.7–×1.5 | ×1.00 |
| Key hint font size | ×0.5–×2.0 | ×1.00 |

**Key corner radius** goes from square keys at 0 to fully pill-shaped keys at 28. It's the same value the theme editor's "Theme-specific corner radii" toggle seeds its own key-radius slider from, if you turn that on for a particular theme. See [Themes](/themes/overview/) for how a theme can override it.

**Key label font size** scales every printed letter on the keys themselves. It's separate from the popup bubble that appears on a key press, which has its own size under [Key press](/reference/settings/keypress/) → Key popup.

**Key hint font size** scales the small corner hint shown on a key: the character or symbol a long-press on that key types. The "Long-press hints" toggle that turns those hints on or off in the first place lives on the [Key press](/reference/settings/keypress/) screen, not here; this slider only controls their size once they're showing. See [Key basics](/typing/basics/) for how long-press hints work.

## Toolbar

<SettingsPath path="Appearance / Toolbar" />

The toolbar is the strip above the keys that carries word suggestions while you type and your pinned tools otherwise.

| Setting | Type | Default | Notes |
|---|---|---|---|
| Show the toolbar | Toggle | On | Turning it off reclaims its height for the keys, but also hides suggestions and every pinned tool. You're asked to confirm before it disables. |
| Swipe down to hide | Toggle | Off | A downward flick anywhere on the toolbar dismisses the keyboard. |
| Only toolbar with hardware keyboard | Toggle | Off | With a physical keyboard attached, drops the on-screen keys and keeps just the toolbar strip. |
| Reverse order for RTL languages | Toggle | On | Mirrors the pinned tool order when the active layout's script runs right-to-left. |
| Spread tools across the bar | Toggle | On | Pinned tools split the available width evenly; off packs them to the left at a fixed size. |
| Toolbar height | Slider, 32–80 dp | 44 dp | The strip carries both suggestions and the toolbar, so this also sets the suggestion row's height. |
| Scroll the toolbar | Toggle | Off | Lets pinned tools scroll sideways at a fixed size instead of shrinking to fit; forces the packed (non-spread) layout while on. |
| Hide toolbar & clipboard on lock screen | Toggle | Off | Hides the whole top strip and blocks the clipboard panel while the phone is locked, so nothing like a copied one-time code sits on a screen anyone can wake. See [Tools](/tools/overview/#which-tools-work-before-you-unlock-your-phone) for how this differs from the tools that work before first unlock. |
| Tool labels | Toggle | Off | Draws a caption under each pinned tool's icon; you'll likely want to raise the toolbar height to fit it. |
| Label text size | Slider, 7–14 sp | 9 sp | Only shown once Tool labels is on. |
| Reset pinned tools | Button | — | Restores the global toolbar to Emoji, Clipboard, and Settings. Resets the global row even while a [mode](/typing/modes/) with its own pinned toolbar is active; to change what a mode pins, edit that mode instead. |
| Tool circle radius | Slider, 0–20 dp | 20 dp | 20 draws a full circle behind each tool icon (Gboard style); smaller values give a rounded square; 0 removes the background, leaving bare icons. Has its own per-theme override in the [theme editor](/themes/editor/#corners). |
| Tool background shape | Row → picker dialog, the same eleven shapes as Key shape | Rounded | The outline of that background. Only Rounded and Cut read the radius above; the rest size themselves off the button. Hidden while the radius is 0, since there is no background to shape. Has its own per-theme override in the [theme editor](/themes/editor/#toolbar). |
| Toolbox layout | Icons / Pills | Icons | Icons is the round-icon grid with a caption under each tool. Pills gives every tool a wide rounded row instead: icon on the left, name beside it, and an arrow on the right for the tools that open something. |
| Toolbox grid size | Slider, 3–6 | 4 per row | Tools per row in the toolbox grid, the grid behind the toolbar's grid button. Fewer per row makes each tool bigger; more fits more tools without scrolling. Only shown while the layout is Icons. |
| Pills per row | Slider, 1–3 | 2 per row | How many pills sit side by side. Only shown while the layout is Pills. |
| Fill pills with the tool color | Toggle | Off | Colors the whole pill with the tool's accent instead of just its icon, flipping the icon and name to whatever reads on top. Needs Colorful tool icons (under <SettingsPath path="Tools" />) to be on. Only shown while the layout is Pills. |
| Swipe the toolbox in pages | Toggle | Off | Breaks the toolbox into fixed pages you swipe sideways, with dots underneath, instead of one grid that scrolls. Applies to both layouts. |
| Tools per page | Slider, 4–40 | 12 per page | How many tools each page holds. Only shown once paging is on. |

## Details & edge cases

- The **Keyboard themes**, **Keyboard font**, and **Icons** rows are shortcuts, not inline settings: each opens its own full screen, so this page only covers what their trailing value means and where the real controls live.
- **Key label font size** and **key hint font size** apply keyboard-wide; they aren't part of any `ThemeSpec`, so switching themes never changes them. See [Themes](/themes/overview/) for what a theme does and doesn't control.
- Turning **Show the toolbar** off is the one guarded setting on this screen: every other toggle and slider here applies immediately. Turning it back on is instant, with no confirmation.
- **Scroll the toolbar** and **Spread tools across the bar** are mutually exclusive in effect: scrolling always forces the packed layout, regardless of what the spread toggle is set to.
- **Reset pinned tools** only touches the global toolbar row. A keyboard [mode](/typing/modes/) that carries its own pinned toolbar keeps it. You reset that from the mode's own editor instead.
