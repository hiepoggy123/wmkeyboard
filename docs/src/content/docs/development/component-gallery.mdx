## LayoutExplorer

Renders any `.wmlayout.json` straight from `app/src/main/assets/layouts/` —
import the file, pass it in. Hover/tap dotted keys for long-press characters;
layouts with a shift layer get a toggle:

## GestureDemo

Stylised, looping gesture explainers (use screen recordings for *real*
behaviour; these are for concepts). Four types:

<GestureDemo type="space-swipe" caption="space-swipe — short spacebar swipe switches language" />

<GestureDemo type="space-hold" caption="space-hold — hold, then drag through the language picker" />

<GestureDemo type="long-press" caption="long-press — accent popup on a held key" />

<GestureDemo type="glide" caption="glide — trace a word without lifting" />

All four freeze to a static end-state under `prefers-reduced-motion`.
