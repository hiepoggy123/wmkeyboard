# Screenshot review

103 shots taken, 220 still to go. Generated by `review.py` — re-run it after any import to pick up new shots.

**How to use this:** open in a Markdown preview, scan the contact sheet, click a thumbnail to jump to its details. Tick the **retake** checkbox under anything that looks wrong, save the file, then run:

```bash
python3 docs/screenshots/retake.py
```

That reads the ticked boxes and hands you the guide + import commands for exactly those shots. Retaking overwrites the image in place — the page already points at that path, so nothing else has to change.
